# Undangan

Koleksi projek undangan digital, tiap projek dalam folder sendiri di root repo ini.

## Struktur folder

```
undangan/
├── Khitanan/     # Projek undangan Walimatul Khitan (Next.js)
├── Nikah/        # (contoh folder masa depan)
├── ...           # Projek undangan lain di sini
└── README.md
```

## Aturan

- Tiap jenis undangan = 1 folder sendiri di root (mis. `Khitanan/`, `Nikah/`, `Aqiqah/`).
- Jalankan `npm install` dan `npm run dev` di dalam folder masing-masing projek, bukan di root.
- Jangan campur projek satu dengan lain dalam satu folder.
